# Sample files

A small, made-up messy folder for trying Sloth Sorter. Everything here was created for this project, contains no real people or companies, and may be used freely.

## How to try it

1. Copy this whole folder somewhere on your computer, for example to your Desktop. Do not run it on the copy inside the repository, because Sloth Sorter moves files.
2. Open Sloth Sorter, choose the copied folder, and press **Take a look**.
3. Read the plan, then press **Tidy**. Press **Undo** afterwards to put everything back.

## What each file is meant to show

| File | What to look for |
|---|---|
| `scan_0412.pdf` | An electricity invoice with a cryptic name. Should go to Bills & Receipts, with the date printed in the document in the new name. |
| `document (1).docx` | A lease letter. Should be read from inside the Word file and sorted to Documents. |
| `notes_final_v2.txt` | Biology lecture notes. Should go to School. |
| `meeting.txt` | Planning meeting notes. Should go to Work. |
| `12122012.txt` | Two recipes under a name made only of digits. |
| `Great Holiday Plans.txt` | Already has a good name, so it is sorted but not renamed. |
| `manual.pdf` | A nine-page manual that opens with safety warnings. The product name only appears near the end, in the legal text. Tests the page sampling and whole-document clues. |
| `lost receipt.pdf` | A scanned receipt: the pages are pictures with no text. Needs **Look at photos** on, and a model that can see. |
| `asdf.png` | A picture of a cafe receipt. Read with the vision model. |
| `IMG_2231.jpg`, `down-img.jpg` | Simple illustrated pictures with cryptic names. Should go to Photos. |
| `Screenshot 2026-10-01 at 10.00.png` | Recognised as a screenshot from its name, without waking the AI. |
| `budget-2026.xlsx` | A spreadsheet. Judged by file type. |
| `photo-editor-setup.exe`, `project-backup.zip`, `song.mp3` | Placeholders. Sorted by type without using the AI. The `.exe` is not a real program. |
| `half-done.crdownload` | Looks like an unfinished download, so it is skipped. |
| `Old stuff/` | A subfolder. Left alone, along with the file inside it. |

Results depend on the model you use, so names and folders can differ a little between runs and computers. That is exactly why Sloth Sorter shows you the plan first.
